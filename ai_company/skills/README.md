# Skills Directory Structure

이 디렉토리는 멀티 에이전트 가상 회사 시스템에서 각 부서 및 공통으로 활용할 스킬(Claude Skill / Tool spec)들을 보관하고 로드하는 공간입니다.

## 폴더 구성

- `global/`: 전사 공통 스킬 (`gsd`, `caveman`, `graphify`, `ponytail` 등 모든 에이전트가 참조)
- `ceo/`: CEO 전용 스킬 (전략 기획, 총괄 오케스트레이션, 최종 검수 등)
- `dev/`: 개발팀 전용 스킬 (코드 작성, 디버깅, PR 리뷰 등)
- `marketing/`: 마케팅팀 전용 스킬 (카피라이팅, SNS 전략, 시장 조사 등)
- `media/`: 미디어팀 전용 스킬 (TTS, 이미지/영상 합성, 스크래핑 등)
- `business/`: 비즈니스팀 전용 스킬 (BM 설계, 시장 분석, 기획서 작성 등)

추후 스킬 묶음(Bundle)을 전달해주시면 오케스트레이터 및 에이전트가 위 폴더별로 자동 분리 및 적재하여 각 직급/부서에 맞게 프롬프트와 툴로 주입합니다.
