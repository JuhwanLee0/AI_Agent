# Skill: Handoff Protocol & Context Compaction (Matt Pocock Style)

에이전트 간 업무 인수인계 시 컨텍스트 낭비를 줄이고, 다음 담당자가 즉시 핵심 작업에 집중할 수 있도록 압축된 인수인계 문서를 전달합니다.

## 핵심 규칙
1. **간결한 컨텍스트 압축**: 대화 전체를 나열하지 않고 핵심 의사결정과 완료된 산출물의 경로(URL 또는 파일 경로)만 링크합니다.
2. **시크릿 및 민감 정보 마스킹**: API Key, 비밀번호, 개인정보가 노출되지 않도록 전수 검사 및 마스킹합니다.
3. **추천 스킬(Suggested Skills) 명시**: 다음 담당자가 호출해야 할 스킬이나 체크리스트를 명시합니다.
4. **구체적 액션 아이템**: 다음 에이전트가 바로 수행할 수 있는 실행 가능한 태스크를 제공합니다.
