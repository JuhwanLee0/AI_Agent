# Global Skill: unlazy - Anti-Laziness Execution Discipline & Depth Tree v2

## 1. unlazy 개요 및 핵심 철학
unlazy는 AI 에이전트 특유의 조기 종료(80% 지점에서 완료 보고), 슬그머니 범위 축소(Scope Narrowing), 기억에 의존한 허위 수치 보고, 끝없는 요약 모드 표류를 기계적으로 차단하는 **안티-게으름(Anti-Laziness) 실행 규율**입니다.
모든 에이전트는 "완료했다는 약속" 대신 **"파일과 체크 명령을 통한 증명"**으로 완료를 입증합니다.

---

## 2. 핵심 7대 실행 수칙

### 1. 0원칙: 작업 전 게이트 파일 작성 (Rule Zero: Gates Before Work)
- 실작업 착수 전, 반드시 인수 조건 파일(`GATES.md` 또는 `gates/leaf-x.md`)을 작성합니다.
- 생각이나 줄글이 아닌, 실행 가능한 셸 명령(`CHECK:`)과 결정적 기대 문자열(`EXPECT:`)을 명시하여 주관적 완료 판단을 차단합니다.
- `EVIDENCE: pending` 상태가 남아있거나 체크박스만 임의로 체크된 것은 **미완료(UNMET)**로 간주합니다.

### 2. Depth Tree v2 & Owns/Needs/Tier 계약
- 작업을 자연스러운 마디(Joint)에 따라 N단계로 분해합니다 (리프는 10분 이상의 온전한 작업 단위).
- **PLAN.md 계약**:
  - `Owns:` 리프가 배타적으로 소유하는 파일 목록 (동일 파일 공유 금지 ➔ 병렬 롤링 디스패치 보장)
  - `Needs:` 선행 의존 리프 ID
  - `Tier:` 모델/노력 수준 (`fast` = 기계적/반복 작업, `smart` = 설계/통합/검증/드라이버)

### 3. 리프 게이트 vs 브랜치 게이트 분리
- **리프 게이트 (`gates/leaf-*.md`)**: 해당 리프가 소유한 파일의 단위 테스트, 파일 존재, 로컬 동작만 빠르게 검증.
- **브랜치 통합 게이트 (`gates/node-*.md`)**: 전체 프로젝트 빌드, 글로벌 타입체크, E2E 통합 테스트, 형제 회귀 검증을 브랜치 통합 시점에 단 1회 실행 ((L \cdot T)$ 낭비 방지).

### 4. 4-Pass Leaf 완결 루프
각 리프 작업 시 반드시 아래 4단계를 순차적으로 통과해야 합니다:
1. **Pass 1 (완전 구현)**: 플레이스홀더, TODO, '나머지는 연습' 없이 100% 실코드로 구현.
2. **Pass 2 (전문가 재검토)**: 해당 도메인 최고 전문가 관점에서 저렴한 구현을 찾아내어 고품질로 개선.
3. **Pass 3 (결함 사냥)**: 엣지 케이스, 경계값, 잠재적 크래시를 집요하게 색출하여 수정.
4. **Pass 4 (비용 제로 폴리싱)**: 상수 튜닝, 미세 모션/가독성 정돈.

### 5. 롤링 디스패치 (Rolling Dispatch)
- 오케스트레이션 모드에서 준비된 리프들을 동시에 병렬 런칭합니다.
- 리프 반환 시 전체 트리가 아닌 해당 리프의 게이트 파일만 즉시 타겟 검증(`gate-check.mjs gates/leaf-x.md`).
- 완료된 리프가 언락한 후속 리프들을 즉시 실행 풀에 투입합니다.

### 6. 보고서 실측 감사 (Report Audit)
- 기억이나 추측으로 보고서에 통계나 수치(예: "총 34개 항목 완료")를 적는 것을 엄격히 금지합니다.
- 모든 보고서 수치는 실측(`CHECK:` 명령) 후 작성하며, **반드시 N/N 게이트 레저를 보고서에 첨부**합니다.

### 7. 인라인 탈출 규칙 (Inline Bail-out)
- 단순 텍스트 수정, 마크다운 문서 보완 등 경미한 작업은 5개의 서브에이전트로 과도하게 분산하지 않고 드라이버가 인라인으로 직접 완결합니다.

## 3. 검증 도구 실행 가이드
```bash
# 단일 리프 또는 전체 게이트 검증
node .agents/skills/unlazy/scripts/gate-check.mjs gates/leaf-1.1.1.md

# 병렬 검증 및 상태 리포트
node .agents/skills/unlazy/scripts/gate-check.mjs --status --jobs 4
```
