# Skill: scrollcraft (프리미엄 스크롤 인터랙션 & 스크롤리텔링 엔진)
*(Ref: nateherkai/scroll-craft — Claude Code skill for premium scroll-driven websites)*

디자인팀장(@디자인팀장) 및 프론트엔드/디자인 사원(@개발_사원C, @디자인_사원)이 인터랙티브 랜딩페이지, 3D/비디오 스크롤 웹사이트, 애플 스타일 제품 소개 페이지를 제작할 때 적용하는 표준 가이드라인입니다.

---

## 1. 핵심 철학 (Core Philosophy)
> **"스크롤(Scroll)은 방문자가 이미 알고 있는 유일한 인터랙션이다. 스크롤을 타임라인(Timeline)으로 취급한다."**

- 마우스 휠/터치는 스크러버(Scrubber)가 되고, 웹페이지는 실제 텍스트가 얹어진 영화(Film)가 됩니다.
- 각 섹션(Act)은 서로 다른 디바이스와 인터랙션으로 동작하여 방문자가 다음 섹션을 계속 스크롤하여 탐색하도록 유도합니다.
- 단순히 "비행 영상 하나 띄우고 위에 글자 얹는 것"을 엄격히 금지합니다 (5개 섹션이 똑같이 동작하면 1개 섹션을 5번 본 것에 불과함).

---

## 2. 4대 기본 척추 규칙 (4 Spine Rules)
1. **다양성이 제품이다 (Variety is the product)**: 한 페이지 내에서 최소 4개 이상의 디바이스 패밀리를 사용하며, 동일한 디바이스를 연속 2번 쓰지 않습니다.
2. **사진 기반 실사 월드 우선 (Photographic unless illustrated)**: 부드러운 무광 저폴리곤 점토(Clay diorama) 스타일의 기본값 사용을 금지합니다.
3. **무분별한 단일 롱테이크 체인 금지 (No continuous chain)**: 하나의 끊어지지 않는 카메라 비행은 가장 비싸고 깨지기 쉬운 구조입니다. 디바이스의 변주를 통해 씬 전환을 자연스럽게 유도합니다 ("연속 여행"이 명시적 기획일 때만 worldflight 사용).
4. **월드가 다르다고 다른 페이지가 아니다 (Different world != Different page)**: 비주얼 테마만 바꾸는 것은 껍데기만 바꾸는 것입니다. 구조(Structure)와 문법(Grammar) 자체를 차별화해야 합니다.

---

## 3. 8대 상호 배타적 페이지 문법 (8 Page Grammars)
동일한 뼈대를 반복하지 않기 위해 프로젝트 특성에 맞춰 아래 8대 문법 중 1가지를 명확히 선택합니다:

1. **Filmic one-shot (영화적 원샷)**: 카메라 궤적 중심의 시네마틱 스크러빙 + 중간 하드 컷 반전.
2. **Chaptered editorial (챕터 에디토리얼)**: 잡지/책의 간지(Intertitle) + 스프레드 페어, 섹션 간 명확한 배경색 하드 컷.
3. **Live surface (라이브 서피스)**: 제품의 실제 콘솔/인터페이스 자체가 페이지가 되어 스크롤에 따라 실시간 로그, 시간축, 데이터 트레이스가 스트리밍.
4. **Continuous world / Worldflight (연속 월드)**: 하나의 고정 스테이지 위에서 끊어짐 없이 깊이(심해, 우주, 축소 모형 등)로 빠져드는 비행 경험.
5. **Typographic poster (타이포그래픽 포스터)**: 타이포그래피 자체가 비주얼이자 인터랙션, 물리 엔진 기반 스크롤 가속도 글자 모션.
6. **Gallery / Catalog (갤러리 & 카탈로그)**: 박물관 표본 색인 형태, 스크롤에 따라 표본 데이터가 축적되고 포인터 브러시로 궤적이 남음.
7. **Split stage (분할 스테이지)**: 화면 중앙 심(Seam)을 기준으로 좌우 대조 상태(Cold vs Ready)가 스크롤에 따라 영역을 확장하며 해소.
8. **Rhythmic cutlist (리듬 컷리스트)**: 플랩 보드(Split-flap) 또는 리드미컬한 짧은 프레임 컷의 빠른 교차.

---

## 4. 6대 차원 지문 게이트 (Fingerprint Gate)
새로운 웹사이트/페이지를 제작할 때, 기존에 만든 어떤 사이트와도 **아래 6개 차원 중 최소 4개 이상 반드시 달라야 합니다**:
1. **문법 (Grammar)**: 위 8대 문법 중 다른 것 채택
2. **내비게이션 (Nav Treatment)**: 미니멀 바, 콘솔 헤더, 지도/웨이포인트 게이지, 표본 인덱스, 분할선 등
3. **히어로 디바이스 (Hero Device)**: 풀블리드 비디오 스크럽, 정적 1.0vh 스틸, 콘솔 콜드 오픈, 거대 타이포 포스터, 모델 글로브 등
4. **액트 시퀀스 형태 (Act-sequence Shape)**: 액트 수, 총 스크롤 길이(vh), `scrub`/`pin`/`flow`/`pan`/`reveal` 등의 조합
5. **클로즈 패턴 (Close Pattern)**: 스포트라이트 스테이지, 전면 반전 슬랩, 수집품 방명록, 프롬프트 입력기, 귀환 샷 등
6. **시그니처 무브 (Signature Move)**: 해당 사이트에만 존재하는 유일무이한 1개의 인터랙션 장치

---

## 5. 감정 곡선(Feeling Curve) & 1개 엔지니어링 피크(Peak)
- **감정 곡선 작성**: 액트별 감정(호기심 ➔ 긴장 ➔ 경외 ➔ 안도)과 화면 요소 매핑.
- **1개의 엔지니어링 피크(Peak)**: 피크-엔드 법칙(Peak-End Rule) 적용. 단 하나의 가장 강렬한 시각/인터랙션 순간에 에셋 예산과 스크롤 여백(Silence)을 집중 배치합니다.
- **침묵(Silence) 배치**: 피크 직전에는 0.5~1.25vh 정도의 절제된 여백을 두어 피크의 임팩트를 극대화합니다.

---

## 6. 자가 검증 루프 (Self-Verification via Headless Browser)
스크롤 기반 웹페이지 완성 후, `scripts/shoot.mjs` 및 `scripts/doctor.mjs` 등을 통해 헤드리스 브라우저로 스크롤 전 구간을 캡처하고 다음 결함을 자동 검증합니다:
1. **Dead scroll (데드 스크롤)**: 휠을 굴려도 화면에 아무 변화가 없는 구간 0건.
2. **Unreached opacity (불투명도 미달)**: 텍스트/카피가 끝내 100% 선명해지지 않고 흐릿하게 남는 버그 방지.
3. **Contrast ratio (실측 명도 대비)**: 배경 영상/이미지가 지나가는 모든 프레임에서 텍스트 명도 대비 4.5:1 이상 유지.
4. **Video decoder stall (비디오 디코딩 정지)**: 클립이 디코딩되지 않고 정지된 포스터로 머무는 결함 방지.
