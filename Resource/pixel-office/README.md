# 픽셀 오피스 — 내 AI 직원들이 일하는 사무실

`.claude/agents/` 폴더가 이미 당신의 조직도입니다. 그걸 읽어서 사무실을 지어줍니다.

에이전트가 지금 **누가 뭘 하는지**, **누가 손 들고 기다리는지**를 한 화면에서 봅니다.

- 설치할 게 없습니다 — 파이썬 기본 기능만 씁니다
- 추가 요금이 없습니다 — 전부 내 컴퓨터 안에서 돕니다
- 코딩 몰라도 됩니다 — 폴더만 있으면 됩니다

---

## 1. 넣기

이 폴더(`pixel-office`)를 통째로 프로젝트의 `.claude/skills/` 안에 넣습니다.

```
내프로젝트/
  .claude/
    agents/          ← 여기 있는 파일들이 조직도가 됩니다
    skills/
      pixel-office/  ← 여기에 넣기
```

## 2. 켜기

프로젝트 폴더에서 한 줄만 칩니다.

```bash
python .claude/skills/pixel-office/scripts/start.py
```

브라우저에 사무실이 뜹니다. **이게 전부입니다.**

- 에이전트가 하나도 없어도 됩니다 → 기본 5인으로 시작합니다
- 포트가 겹치면 알아서 다음 번호를 찾습니다

## 3. 실제 작업이 화면에 뜨게 하기

위 상태에서는 사무실만 있고 사람이 안 움직입니다. 클로드 코드가 보내는 신호를 연결해야 합니다.

먼저 **뭐가 바뀌는지만** 봅니다(파일은 안 바뀝니다):

```bash
python .claude/skills/pixel-office/scripts/wire_hooks.py --settings .claude/settings.local.json --check
```

`보존된 기존 훅: N개` 숫자가 연결 전과 같으면 안전합니다. 그러면 실제로 연결합니다:

```bash
python .claude/skills/pixel-office/scripts/start.py --wire
```

- **기존 설정을 덮어쓰지 않습니다.** 옆에 한 줄을 얹고, 바꾸기 전에 `.bak` 백업을 뜹니다
- 되돌리려면: `wire_hooks.py --settings ... --remove`

## 4. 화면 보는 법

| 보이는 것 | 뜻 |
|---|---|
| 책상에서 점 세 개 | 파일을 쓰거나 고치는 중 |
| 돋보기 | 찾아보는 중 |
| **노란 옷 + `?`** | **손 들고 당신을 기다리는 중** |
| 붉은 옷 (버그존) | 방금 실패한 작업 |
| 흐려지고 `zzz` | 한동안 소식이 없음 |

- **캐릭터를 클릭**하면 그 직원이 무슨 일을 하는 사람인지, 지금 뭘 하는지가 옆에 뜹니다
- `c` 키 — 화면 위 CCTV 효과를 진하게/옅게

## 5. 자리가 이상하면

역할은 이름과 설명의 낱말로 자동 배정합니다. 그래서 가끔 엉뚱한 자리로 갑니다.
(실제 사례: 설명에 "리서치"라는 말이 있던 검수 담당이 리서치 코너로 갔습니다.)

`.pixel-office/org.json` 을 열어 그 사람의 `zone` 값만 바꾸면 됩니다.
**손으로 바꾼 자리는 다음에 다시 켜도 그대로 유지됩니다.**
`desk` / `research` / `meeting` / `server` 중 하나입니다.

---

## 이건 못 합니다 (먼저 말씀드립니다)

**감시 화면입니다.** 에이전트를 막거나, 되돌리거나, 중간에 세우거나, 돈이 얼마 나가는지 알려주지 않습니다.
실행 전 검사도 안 합니다. 보이는 것뿐이고, 그게 이 도구가 파는 전부입니다.

그런데 보이는 것만으로 행동 하나가 바뀝니다 — 손 들고 기다리는 직원을 몇 시간씩 방치하지 않게 됩니다.

## 알아두면 좋은 것

서브에이전트 신호는 생각보다 잘 안 옵니다. 전용 신호가 아예 안 오는 경우가 보고돼 있고,
와도 이름 칸이 비어 있기도 합니다. 그래서 이 도구는 **세 겹으로 받습니다** —
일을 넘기는 순간의 신호에서 이름을 먼저 챙기고, 전용 신호가 오면 갱신하고,
둘 다 없으면 기록 파일을 읽습니다. 끝났다는 신호를 못 받은 자리는 시간을 재서 정리합니다.

## 안 될 때

| 증상 | 볼 곳 |
|---|---|
| 브라우저에 엉뚱한 화면 | 포트를 남이 쓰는 중 → `--port` 로 다른 번호 |
| 사무실은 뜨는데 아무도 안 움직임 | 신호 미연결 → `--wire` |
| 짧은 작업이 안 보임 | 정상입니다. 8초는 자리를 지키게 해뒀습니다 |
| 이름이 `main` 으로만 나옴 | 정상입니다. 서브에이전트를 띄우면 이름이 붙습니다 |
