# 졸라맨(Stick Figure) 지식·경제 영상 제작 치트키 스킬

시청 지속 시간을 극대화하는 **3단계 원고 작성(3막 8장)**부터 **2D 졸라맨 이미지 프롬프트 자동 추출** 및 **Google Labs Whisk 자동 이미지 생성/다운로드**까지 원스톱으로 처리합니다.

---

## 🎬 5단계 올인원 파이프라인

```
[1. 소재 분석] ➔ [2. 3막 8장 뼈대] ➔ [3. 1,500자 상세 대본] ➔ [4. 졸라맨 프롬프트 추출] ➔ [5. Whisk 자동 다운로드]
```

---

## STEP 1. 소재 분석 및 기획 (벤치마킹)

유튜브 검증 영상 URL 또는 분석할 주제/뉴스/데이터를 기반으로 콘텐츠를 해부합니다.

### 📌 프롬프트 템플릿
```markdown
# 역할 부여
당신은 15년 경력의 수석 경제 분석가이자, 복잡한 지표를 일반인이 이해하기 쉬운 비유로 풀어내는 유튜브 콘텐츠 기획 전문가입니다. 시청 지속 시간을 최적화하는 콘텐츠를 기획하세요.

# 작업 목표
제공된 [주제/데이터/뉴스/URL]를 바탕으로 시청자가 깊이 공감할 수 있는 고품격 지식/경제 분석 원고로 재창조합니다.
기승전결 3막 8장으로 주요 내용을 정리해 주세요.
```

---

## STEP 2. 뼈대 잡기 (3막 8장 구조화)

한 번에 본문을 작성하지 않고, 강력한 후킹과 장별 연결고리(브릿지)를 설계합니다.

### 📌 프롬프트 템플릿
```markdown
# 작업 목표
3막 8장에 도입부를 추가하는 구조로 뼈대를 만들어 주세요.
- 기획안을 바탕으로 1장당 400자 내외로 구성
- 도입부는 역설적이거나 반어적인 표현을 사용해 강력하게 후킹(Hooking)
- 장과 장 사이의 이음새는 다음 내용에 강한 호기심을 유발하도록 설계
```

---

## STEP 3. 본문 작성 (살 붙이기)

각 장별로 호흡을 조절하며 상세 대본을 작성합니다. (장 단위 분할 생성)

### 📌 필수 집필 가이드 (Tone & Manner)
1. **분량**: 공백 포함 한글 1,300 ~ 1,500자 내외.
2. **문체 스타일**:
   - 문장은 짧고 간결하게 끊기 (가독성 및 성우 호흡 최적화).
   - 문장 종결 어미: `~입니다`, `~하죠`, `~라는 겁니다` 등 친절하면서도 단호한 어조.
   - **비유의 구체화**: 추상적인 수치 대신 눈앞에 그려지는 직관적 비유 활용.
   - **냉철하지만 따뜻한 톤**: 팩트는 날카롭게 전달하되 시청자의 자산/미래를 진심으로 걱정하는 어조.
3. **몰입 장치**: 초반 30초 안에 듣지 않으면 손해를 볼 것 같은 강력한 질문/숫자로 시작.
4. **브릿지 멘트**: 장 끝부분에 다음 장이 궁금해 미칠 것 같은 연결 멘트 필수 삽입.
5. **출력 형식**: 소제목, 시간표, BGM 안내를 모두 제외하고 오로지 **줄글 형태의 원고**만 출력.

---

## STEP 4. 2D 졸라맨 이미지 프롬프트 자동 추출

완성된 대본을 1~2문장 단위로 쪼개어 Google Whisk / 이미지 생성 AI용 영문 프롬프트로 변환합니다.

### 🎨 프롬프트 고정 규칙 (Style Factor)
- **대표 스타일**: `A flat vector-style cartoon, stick figure animation`
- **인물 특징**: 하얀 피부의 단순한 졸라맨(Stick figure), 다양한 직업/상황별 복장 및 제스처
- **배경 및 구도**: 단순한 미니멀 배경, 인물의 감정/행동 극대화, **16:9 와이드 비율**
- **문구 주의사항**: 이미지 내 텍스트가 필요할 경우 영문 프롬프트 안에 한국어 문구(`"한국어 텍스트"`)로 표기

### 📌 프롬프트 출력 포맷
```text
{번호}
{문장}: [원문 대본 문장]
{영문}: A flat vector-style cartoon, stick figure with white skin wearing [의상/행동], [단순 배경], minimalist 2D line drawing, 16:9 aspect ratio
{번역}: [프롬프트 한국어 해석]
```

---

## STEP 5. 자동화 스크립트 실행

### 1) 대본 ➔ 프롬프트 파일 자동 변환
대본 텍스트 파일(`script.txt`)이 준비되면 아래 스크립트로 순수 영문 프롬프트 모음(`whisk_prompts.txt`)을 생성합니다:
```bash
python3 scripts/stickman/prompt_extractor.py --input script.txt --output whisk_prompts.txt
```

### 2) Google Labs Whisk 자동 이미지 생성 & 다운로드
추출된 프롬프트 목록으로 크롬 브라우저를 자동 제어하여 고화질 이미지를 순서대로 다운로드합니다:
```bash
node scripts/stickman/whisk_automator.js --prompts whisk_prompts.txt --out output/images/
```
